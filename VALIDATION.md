# Проверка версии 2.0

Исправления проверяются по реальным ошибкам предыдущей версии, а не сравнением
с заранее прописанными демо-результатами.

- 35 тестов API/правил/чтения файлов: пустой ввод, границы чисел, RU/KZ,
  эквиваленты, отрицания, опыт >10 лет, стоимость, отсутствие выдуманных компаний,
  страницы после десятой, сканы, ограничения объёма/страниц, реальные multipart,
  занятый сервер, недоступная модель, CORS и доступность статических файлов.
- Браузер: 320/390/768/1024 px без горизонтального переполнения, реальный API,
  экспорт JSON, сравнение и равенство, повторная загрузка файла, инъекция HTML,
  HTTP 503, несовместимая схема, очистка сессии; нет ошибок JavaScript.
- Сохранённая модель загружена локально с проверкой SHA-256; инференс выполнен.
- Скриншоты test-results/desktop.png, mobile.png, result.png создаются проверкой.

Docker Desktop в проверяемой среде не смог запуститься ("Docker Desktop is unable
to start"). Сборка контейнера здесь пока не проверена. Публикация Space требует
входа Hugging Face. Эти пункты не следует
считать выполненными на основании локальных тестов.

Нет независимой экспертной разметки: точность и полнота на реальных закупках
не измерены. scripts/evaluate.py подготовлен для такой выборки. OCR, подключение
истории поставщиков и юридическая экспертиза правил не реализованы; интерфейс
явно сообщает об этих ограничениях.
