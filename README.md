# TenderAI 2

Предварительная проверка условий закупок с цитатами и страницами. Один API для
загрузки файлов, вставленного текста и сравнения. Фронтенд без внешних шрифтов,
CDN и сборщика. Исходный прототип сохранён в истории Git.

## Локальный запуск

Python 3.12+:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000. Не открывайте index.html через file://.
По умолчанию локально используется явно обозначенный режим текстовых правил.

Существующее окружение этого workspace:

```powershell
Set-Location C:\tenderai-1
C:\tenderai\.venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

## Экспериментальная ML-модель

Артефакты созданы scikit-learn **1.8.0**. Старый Space ставил 1.4.2 и ссылался на
отсутствующий model_local. Здесь версии согласованы, SHA-256 артефактов проверяется
перед загрузкой pickle. Никогда не заменяйте их файлами из недоверенного источника.

```powershell
python -m pip install -r backend/requirements-ml.txt
python -m backend.download_model
$env:ENABLE_ML = '1'
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

В текущем workspace можно использовать `$env:EMBEDDER_PATH = 'C:\tenderai\model_local'`.
Docker включает ML, скачивает закреплённую ревизию кодировщика при сборке, а при
запуске работает без скачивания моделей. Если включённая модель не загрузилась,
health возвращает 503, анализ также 503. Скрытого переключения алгоритма нет.

ML-показатель считается по фрагментам до 120 токенов и не входит в индекс правил.
Это изменение метода относительно старого целиком усечённого текста; показатель
не валидирован. Более 256 фрагментов: ML явно пропускается, правила проверяют весь
извлечённый текст. Это не вероятность коррупции или нарушения законодательства.

## API

- GET `/api/health`: готовность, версия схемы и явный режим.
- POST `/api/analyze-text`: JSON `{ "text": "...", "filename": "..." }`.
- POST `/api/analyze-file`: multipart, поле `file` (PDF/TXT UTF-8).
- `/health` и `/analyze` — алиасы. Формат результата изменён на schema_version=2;
  старый фронтенд не совместим, обновляйте его вместе с сервером.

До 10 МБ, 100 страниц, 300 000 символов, минимум 30 букв. PDF обрабатывается в
отдельном процессе с пределом 25 секунд. Два одновременных анализа; занятый сервер
возвращает 429. Общий лимит соединений задаётся uvicorn в Dockerfile.
Пустые, зашифрованные, повреждённые файлы и сканы не получают «чистую» оценку.
Страницы с недостаточным текстом явно отмечаются; итоговый индекс не рассчитывается.
OCR пока не реализован. Изображения внутри текстовых страниц также не анализируются.

Файлы/отчёты не сохраняются приложением: обработка в памяти/временном upload-файле,
который закрывается после запроса. Отчёты в браузере живут только до обновления
страницы. Серверные access-логи содержат пути запросов, не содержание документов.
Инфраструктура хостинга регулируется её собственными условиями.

## Развёртывание

Рекомендуется публиковать весь этот репозиторий в существующий Docker Space:
один origin обслуживает фронтенд и API. GitHub Pages также поддерживается:
config.js выбирает существующий API для домена github.io. Для другого отдельного
домена измените apiBase и ALLOWED_ORIGINS. Не включайте wildcard CORS.

Подготовить и проверить Docker: `docker build -t tenderai:2 .`, затем
`docker run --rm -p 7860:7860 tenderai:2`. Сборка ML требует сети и места для PyTorch.

Публикация после входа в Hugging Face:

```powershell
hf auth login
python scripts/deploy_space.py --space entelexiya/tenderai-api
```

Токен не хранится в репозитории. Скрипт загружает только явно перечисленные файлы,
фиксирует родительский commit, удаляет устаревшие серверные модули и не отправляет
датасеты, окружение, тестовые документы или учётные данные. Проверить после сборки:
`/api/health`, загрузку PDF, цитаты/страницы, экспорт и мобильную версию.

## Качество и ограничения

508 строк / 474 уникальных текста в предоставленном обучающем CSV — это не
независимая тестовая выборка. Подтверждённая точность не заявляется. Для её измерения
нужны документы, независимо размеченные экспертами: категории, страницы и цитаты.
Регрессионные тесты проверяют исправленные ошибки, не доказывают качество на рынке.
Бренды, дилерство, сроки и опыт — признаки для уточнения, не правовые вердикты.
Правила RU/KZ покрывают ограниченный словарь; отрицания и сложный контекст могут
потребовать ручной проверки. История поставщиков выключена до подключения источника.
